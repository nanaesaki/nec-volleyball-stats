ブラウザ操作だけで試合データを蓄積する手順

会社のPCなどローカル環境でPythonを動かせない場合でも、GitHubのブラウザ画面から GitHub Actions を実行することで backend/data/matches.json に蓄積され、この画面に自動反映されます。

  1. GitHubリポジトリ（nec-volleyball-stats）の Actions タブを開きます。
  2. 左メニューの Ingest SV.LEAGUE Match Data を選択し、右上の Run workflow ボタンを押します。
  3. 帳票URL・Live Score URL・NECコメント・対戦相手コメントを入力して緑色の Run workflow を実行します。
  4. 完了後、このダッシュボード右上の 「↻ データ更新」（またはブラウザ再読み込み）を押すと、新しい試合がドロップダウンと「蓄積・全試合分析」に追加されます。
